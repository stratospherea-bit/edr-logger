# EDR Logger

iPadの加速度センサーから垂直方向の揺れ（Δg）を計測し、EDRに近い指標を推定・記録するPWAです。
推定値は機上EDRの代替ではありません。運航上の判断には使用しないでください。

## GitHub Pagesへの公開

1. GitHubで新しいリポジトリを作成します（Public。例: `edr-logger`）。
2. このフォルダのファイルをすべてリポジトリ直下にアップロードします
   （index.html、sw.js、manifest.webmanifest、icon-180.png、icon-192.png、icon-512.png）。
3. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します。
4. 数分後に `https://<ユーザー名>.github.io/edr-logger/` で開けるようになります。

## iPadへの追加

1. SafariでURLを開き、共有メニューから「ホーム画面に追加」を選びます。
2. 地上でネットにつながっているうちに一度起動しておくと、以降は機内（オフライン）でも起動できます。

## 使い方

- 「記録開始」をタップし、モーションと位置情報へのアクセスを許可します。
- 最初の約8秒はフィルタの安定待ちです。その後、1秒ごとに推定EDRが更新・保存されます。
- 記録中はこの画面を前面に表示したままにしてください。ほかのアプリに切り替えたり画面がロックされたりすると計測が止まります。
- 揺れを感じたら「LGT / MOD / SEV」をタップすると、その時刻に体感が記録されます。
  機体のEDR表示やPIREPの値は「メモ」で残せます。
- 「記録停止」のあと、一覧の「CSVを書き出す」で共有シートからファイルやメールに保存できます。

## 計算方法

1. `accelerationIncludingGravity` を約60Hzで取得
2. ローパス（時定数2秒）で見かけの重力方向を推定し、加速度をその方向へ射影して垂直成分を算出
   （iPadの向きや置き方に依存しません。持続的な旋回・引き起こし荷重もここで大部分が除かれます）
3. 0.1〜2Hzのバンドパスで操縦荷重と高周波振動を除去 → Δg
4. 集計窓（初期値10秒）のRMSを σΔg とし、推定EDR = k × σΔg

## 係数kの校正

初期値 k = 4.0 は仮の値です。機種・重量・速度で変わるため、実データで合わせてください。

1. 機体のEDR値（表示・ACARS・社内データなど）やPIREPを「メモ」で記録します。
2. CSVの `sigma_dg` と、その時刻の機体EDRを並べます。
3. 原点を通る直線で回帰すると、傾きが k になります（k = Σ(EDR×σ) / Σ(σ²)）。
4. 設定画面で k を変更します。巡航と上昇・降下で値が違う場合は、用途に合わせて選んでください。

LGT / MOD / SEV のしきい値（初期値 0.10 / 0.25 / 0.45）も設定で変更できます。

## CSVの列

| 列 | 内容 |
|---|---|
| time_utc | 記録時刻（UTC） |
| elapsed_s | 記録開始からの秒数 |
| edr_est | 推定EDR |
| sigma_dg | 集計窓内のΔgのRMS [g] |
| peak_dg_window / peak_dg_1s | 集計窓内／直近1秒の最大\|Δg\| [g] |
| category | NIL / LGT / MOD / SEV |
| sample_hz | 実測サンプリング周波数 |
| k, window_s | その時点の設定値 |
| lat, lon, gps_alt_m, gps_alt_ft, ground_speed_kt, track_deg, gps_acc_m | GPS（取得できた場合） |
| mark | 体感マーク・メモ |

## 注意

- iPadはマウントやクリップにしっかり固定してください。手持ちや膝の上では人の動きが混ざります。
- GPSはCellularモデルのみ。Wi-Fiモデルでは位置の列が空欄になります。
- 画面維持（Wake Lock）が「非対応」と表示される場合は、iPadの自動ロックを一時的に「なし」にしてください。
- アプリを更新したら `sw.js` の `CACHE` の番号（v1 → v2）を上げてください。上げないと古い版が表示され続けます。
- 会社管理のEFBで使う場合は、事前に社内のEFB運用規程を確認してください。
