# EDR Logger

iPadの加速度センサーから垂直方向の揺れ（Δg）を計測し、EDRに近い指標を推定・記録するPWAです。
推定値は機上EDRの代替ではありません。運航上の判断には使用しないでください。

## GitHub Pagesへの公開

1. GitHubで新しいリポジトリを作成します（Public。例: `edr-logger`）。
2. このフォルダのファイルをすべてリポジトリ直下にアップロードします
   （index.html、sw.js、manifest.webmanifest、icon-180.png、icon-192.png、icon-512.png）。
3. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存します。
4. 数分後に `https://<ユーザー名>.github.io/edr-logger/` で開けるようになります。

## iPadへの追加

1. SafariでURLを開き、共有メニューから「ホーム画面に追加」を選びます。
2. 地上でネットにつながっているうちに一度起動しておくと、以降は機内（オフライン）でも起動できます。

## 使い方

- 「記録開始」をタップし、モーションと位置情報へのアクセスを許可します。
- 最初の約8秒はフィルタの安定待ちです。その後、1秒ごとに推定EDRが更新・保存されます。
- 記録中はこの画面を前面に表示したままにしてください。ほかのアプリに切り替えたり画面がロックされたりすると計測が止まります。
- 揺れを感じたら「LGT / MOD / SEV」を、機体のEDR値が分かったら「機体EDR」欄に入力して「校正」をタップします。
  どちらもその時刻に記録され、k₀ の校正に使われます（下記）。
- 重量・燃料消費量・TAS・FLは、分かったときに入力すればその時点から反映されます。
- 「記録停止」のあと、一覧の「CSVを書き出す」で共有シートからファイルやメールに保存できます。

## 地図で見る（KML）

記録一覧の「Google Earthで開く」で、KMLファイルを作って共有シートを開きます。
共有シートにGoogle Earthがあればそれを選びます。なければ「"ファイル"に保存」してから、
Google Earthのプロジェクトで読み込んでください。Googleマイマップにも読み込めます。

- 航跡: カテゴリで色分けした線（灰 NIL、緑 LGT、アンバー MOD、赤 SEV。強いほど太い）。GPS高度付きで立体表示されます。
- ピン: MOD以上の揺れのまとまりごとに1本、そのまとまりの最大地点に立てます。
  60秒以内の再発は同じまとまりとして扱い、10秒未満の単発は除外します（SEVは短くても残します）。
- 小さいピン: 体感・機体EDR・メモを入力した地点。
- 位置情報のない記録は地図に表示できません。

## 計算方法

1. `accelerationIncludingGravity` を約60Hzで取得
2. ローパス（時定数2秒）で見かけの重力方向を推定し、加速度をその方向へ射影して垂直成分を算出
3. 0.1〜2Hzのバンドパスで操縦荷重と高周波振動を除去 → Δg
4. 集計窓（初期値10秒）のRMSを σΔg とする
5. 推定EDR = k × σΔg、k = k₀ × 補正

補正は突風荷重の式（Δn ∝ ρ·V / (W/S)）にもとづきます。

    補正 = (W / W基準) × (ρ基準 × TAS基準) / (ρ × TAS)

ρは標準大気の密度です。基準状態の初期値は 1,000,000 lbs、FL350、TAS 480 kt です。
巡航での使用を前提にしています。

## 飛行状態の入力

| 項目 | 入力したとき | 入力しないとき |
|---|---|---|
| 現在重量 | その値から再スタート | 初期重量（1,000,000 lbs）から消費量に応じて減少 |
| 燃料消費量 | その時点から新しい消費量で減少 | 400 lbs/分 |
| TAS | 入力値を使用（空欄に戻すと基準値） | 基準TAS |
| FL | 入力値を使用（空欄に戻すとGPS） | GPS高度、取れなければ基準FL |

記録を停止すると、次のフライトに備えて既定値に戻ります。記録開始前に入力した値は、そのフライトの初期値になります。

## k₀ の自動校正

記録中に次の入力をすると、k₀ が自動で更新されます。結果は「メモ」としてCSVの mark 列にも残ります。

- **機体EDR**：値（0.05以上）を入れて「校正」をタップします。その時点の σΔg と補正から k₀ の候補を逆算し、現在の k₀ をそちらへ近づけます。
- **体感（LGT / MOD / SEV）**：推定EDRがそのカテゴリの範囲外だったときだけ、範囲の代表値に向けて半分の重みで k₀ を近づけます。範囲内なら変更しません。

近づける割合は、校正点が少ないうちは大きく（1点目は50%）、増えるほど小さくなり、最小10%で落ち着きます。1回の補正で k₀ が3倍以上・3分の1以下に動くことはありません。

初期の k₀ は設定画面の「初期の係数 k₀」で変更できます（変更すると校正結果はリセットされます）。「校正をリセット」で初期値に戻すこともできます。

LGT / MOD / SEV のしきい値（初期値 0.10 / 0.25 / 0.45）も設定で変更できます。

## CSVの列

| 列 | 内容 |
|---|---|
| time_utc | 記録時刻（UTC） |
| elapsed_s | 記録開始からの秒数 |
| edr_est | 推定EDR |
| sigma_dg | 集計窓内のΔgのRMS [g] |
| peak_dg_window / peak_dg_1s | 集計窓内／直近1秒の最大\|Δg\| [g] |
| category | NIL / LGT / MOD / SEV |
| k_eff, k0, correction | 使用した k、その時点の k₀、補正係数 |
| weight_lbs, fl, tas_kt | 補正に使った重量・FL・TAS |
| fl_src, tas_src | 値の出どころ（input / gps / ref） |
| sample_hz, window_s | 実測サンプリング周波数、集計窓 |
| lat, lon, gps_alt_m, gps_alt_ft, ground_speed_kt, track_deg, gps_acc_m | GPS（取得できた場合） |
| mark | 体感・機体EDR・メモ |

## 注意

- iPadはマウントやクリップにしっかり固定してください。手持ちや膝の上では人の動きが混ざります。
- GPSはCellularモデルのみ。Wi-Fiモデルでは位置の列が空欄になります。
- 画面維持（Wake Lock）が「非対応」と表示される場合は、iPadの自動ロックを一時的に「なし」にしてください。
- アプリを更新したら `sw.js` の `CACHE` の番号（v1 → v2）を上げてください。上げないと古い版が表示され続けます。
- 会社管理のEFBで使う場合は、事前に社内のEFB運用規程を確認してください。
